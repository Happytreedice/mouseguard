# Sheet art (placeholders)

The character sheet, the item sheets, the Test dialog and the chat cards copy the layout of the
"Legend in the Mist" sheet (mist-engine-fvtt). That sheet draws its look with raster images. Those images are
proprietary, so every one of them is replaced here by a **placeholder** with the same role, file format, colour mode,
pixel size and alpha layout. The CSS uses each placeholder exactly the way mist-engine uses the original (same
`border-image` slices, same `background-size`).

To restyle the sheets, drop your own image in under the **same file name** (same format and size, or at least the same
aspect ratio and the same transparent margin/rim inside the slice). No code change is needed; rebuild the CSS only if you
rename a file.

The placeholders are generated by `scripts/make-placeholders.py` (Pillow with WebP support):

```
python3 -I scripts/make-placeholders.py
```

Running it again overwrites every file listed below with a fresh placeholder.

## Fonts

`assets/fonts/Caveat-Regular.ttf` (handwritten text: Belief, Goal, Instinct) is the only font of the reference sheet
that has Cyrillic glyphs. It is licensed under the SIL Open Font License 1.1, see `assets/fonts/OFL.txt`.
All other text uses a Cyrillic-capable system serif stack (Palatino Linotype, Book Antiqua, PT Serif, Noto Serif,
Georgia, DejaVu Serif).
